## Incorrect or misleading output found during the session, and the fix

| Problem | How it was found | Fix |
|---|---|---|
| Service methods named `list` shadowed the builtin inside the class body, so later annotations `list[str]` raised `TypeError` at import | import smoke test | renamed to `page` |
| A forwarder unit test asserted that `connection: keep-alive` was removed, but httpx adds its own `connection` header | failing unit test | assert on `host` instead |
| Autogenerated migration used `server_default=sa.text('0')` for a boolean (SQLite-ism, invalid on PostgreSQL) | migration review | `sa.false()` |
| Partial unique indexes declared only with `postgresql_where` became *full* unique indexes on SQLite in a local check | local shim run | added `sqlite_where` too |
| Planned to use `SlowAPIMiddleware`; its route lookup takes the *last* matching route, which would be the catch-all proxy route, silently exempting admin endpoints | reading slowapi source | router-level dependency wrapping a slowapi-decorated gate |
| A batch of shell heredocs failed to parse, writing no files | tool error | wrote files through a bundle splitter |
